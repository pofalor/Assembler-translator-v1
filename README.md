# Assembler Translator

Учебный двухпросмотровый транслятор с языка ассемблера для программ в абсолютном формате. Приложение написано на C# (.NET 9): графический интерфейс — WPF, логика транслятора вынесена в отдельную библиотеку.

Поддерживаемые типы адресации: **прямая** и **непосредственная**.

## Возможности

- Двухпросмотровая трансляция исходного кода в объектный (двоичный) код.
- Настраиваемая таблица кодов операций — команды можно задавать/менять прямо в интерфейсе.
- Построение таблицы символических имён (ТСИ) на первом проходе.
- Формирование вспомогательной таблицы (результат первого прохода) и объектного кода (результат второго прохода).
- Подробные сообщения об ошибках для каждого прохода: контроль формата строк, диапазонов значений, дублирования меток, переполнения памяти (адресное пространство — 2²⁴ байт) и корректности директив START/END.

## Структура проекта

| Проект | Описание |
|---|---|
| `SysProgTemplate` | WPF-приложение (интерфейс): окна ввода исходного кода и таблицы команд, вывод результатов проходов и ошибок |
| `SysProgTemplateShared` | Библиотека с логикой транслятора: `Assembler` (первый и второй проходы), `Parser` (разбор текста на токены), структуры данных и исключения |

Ключевые файлы:

- `SysProgTemplateShared/Assembler.cs` — алгоритмы первого (`FirstPass`) и второго (`SecondPass`) проходов, ведение ТСИ.
- `SysProgTemplateShared/Helpers/Parser.cs` — разбор исходного текста и таблицы кодов операций.
- `SysProgTemplateShared/Structure/` — модели: `Command`, `CodeLine`, `Operand`, `SymbolicName`.
- `SysProgTemplate/MainWindow.xaml(.cs)` — главное окно приложения.

## Сборка и запуск

Требуется [.NET SDK 9](https://dotnet.microsoft.com/download) и Windows (проект использует WPF).

```bash
git clone https://github.com/pofalor/Assembler-translator-v1.git
cd Assembler-translator-v1
dotnet run --project SysProgTemplate
```

Либо открыть `SysProgTemplate/SysProgTemplate.sln` в Visual Studio и запустить проект `SysProgTemplate`.

## Использование

1. В поле **«Исходный текст»** ввести программу на ассемблере (при запуске подставляется пример).
2. При необходимости отредактировать **«Таблицу кодов операций»** — по одной команде на строку в формате `ИМЯ КОД ДЛИНА` (код и длина — в 16-ричной системе; код от 0 до 3F, длина 1, 2 или 4 байта).
3. Нажать **«Первый проход»** — заполнятся вспомогательная таблица и ТСИ, ошибки появятся в поле «Ошибки первого прохода».
4. Нажать **«Второй проход»** — сформируется объектный код, ошибки появятся в поле «Ошибки второго прохода».

### Команды по умолчанию

| Команда | Код | Длина (байт) |
|---|---|---|
| `JMP` | 1 | 4 |
| `LOADR1` | 2 | 4 |
| `LOADR2` | 3 | 4 |
| `ADD` | 4 | 2 |
| `SAVER1` | 5 | 4 |
| `INT` | 6 | 2 |

### Директивы

| Директива | Назначение |
|---|---|
| `START` | Начало программы и её загрузочный адрес (обязательна, с меткой — именем программы) |
| `END` | Конец программы; необязательный операнд — адрес точки входа |
| `WORD` | Резервирует слово (3 байта) с заданным значением |
| `BYTE` | Резервирует байт: число 0–255, строка `C"..."` или 16-ричная строка `X"..."` |
| `RESW` | Резервирует N слов (3·N байт) |
| `RESB` | Резервирует N байт |

### Формат строки исходного кода

```
[МЕТКА] КОМАНДА|ДИРЕКТИВА [ОПЕРАНД1] [ОПЕРАНД2]
```

- Метка: до 10 символов, начинается с латинской буквы, далее латинские буквы, цифры и `_`.
- Регистры: `R1`–`R16`.
- Операндом может быть метка (прямая адресация), число (непосредственная адресация), пара регистров или строка (для `BYTE`).

### Пример программы

```asm
PROG  START   100
      JMP     L1
B1    WORD    40
B3    BYTE    C"Hello!"
B4    BYTE    12
L1    LOADR1  B1
      LOADR2  B4
      ADD R1  R2
      SAVER1  B1
      INT     200
      END
```

## Формат объектного кода

Результат второго прохода — записи трёх типов:

- `H имя_программы адрес_загрузки длина` — заголовок;
- `T адрес длина код` — тело (машинный код команды или данные);
- `E адрес_входа` — конец программы с адресом точки входа.

В байте кода операции старшие 6 бит — код команды, младшие 2 бита — тип адресации (`00` — непосредственная, `01` — прямая).
